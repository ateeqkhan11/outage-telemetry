# Phrases that must never appear in marketing copy (site/, templates/public/, templates/email/).
# One case-insensitive Python regular expression per line; blank lines and lines starting with # are ignored.
# The Methodology page is checked against these too, after removing phrases in methodology-allow.txt.
# Founders' rule: the only marketing claim is the approved line (see README / PRD section 8.1).

independently (verified|measured|monitored|confirmed)
