Nimbus Index · how it works

An independent referee for cloud outages

We watch AWS us-east-1 from outside AWS, from several independent networks, every few seconds. Every result is signed so nobody, including us, can change it later. When an insurer has to decide whether an outage happened and a policy pays, our record is the neutral second opinion.

The business story

Parametric cloud cover pays automatically when an agreed outage happens. The hard part is agreeing that it happened. That is the gap we fill.

1 · Before

An MGA sells outage cover

A business that runs on AWS buys a policy: "if us-east-1 is down for 2 hours, you get paid."

2 · The event

AWS us-east-1 fails

S3, DynamoDB or another core service stops answering for many customers.

3 · Nimbus Index

Our signed record confirms it

Probes on networks run by different companies all saw the failure. The MGA checks its own data against ours.

4 · After

Payout, no dispute

Two independent sources agree, so the claim pays in hours instead of weeks of arguing.

The technical architecture

Read it top to bottom: what we measure, who measures it, where the evidence goes, how an outage gets called, and who sees it.

What happens every minute

  1. second 0, 10, 20, 30, 40, 50Probe. Each network calls the five AWS services and google.com, and times each call.
  2. same secondLabel. Each call becomes ok, timeout, server error, no connection, throttled, or "AWS answered but refused us". Only the first four can count as AWS being down.
  3. end of the minuteSign and chain. Each result gets that network's signature and the fingerprint of the result before it.
  4. every 5 minutesPublish. The GitHub run collects the new results from all networks into the public data branch and rebuilds the status summary.
  5. same runDecide. The outage rule reads the last 10 minutes. Two operators agreeing on a failure means down.
  6. within a few minutesShow. The dashboard, and soon the app and its API, show the new status.

Why it is built this way

Probes sit outside AWS

A monitor inside AWS goes dark in the very outage it should record. The Oregon Lambda is inside AWS, so it is a reference view and never counts.

Different companies, not just different machines

If one provider has a bad day, its probes all fail together. GitHub runs on Microsoft, so it and Azure count as one. We need Cloudflare plus one more.

Every result is signed

An insurer paying out on our data must trust that nothing was edited after the fact, including by us. The signatures let them check that themselves.

The record is public, the app is gated

Open evidence is the trust story. The sign-in covers the convenience: reports, downloads and API keys. It also shows us which firms are interested.
