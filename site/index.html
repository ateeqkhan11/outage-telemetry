A reference clock for cloud outages

A parametric payout turns on two times: when an outage started and when it ended. The cloud provider's status page, crowd reports and outside measurement often disagree on both. Nimbus Index is a reference index in development, built on selected AWS us-east-1 API checks, with early data collection under way.

Key terms of the pilot

What it is
A third-party record of when an AWS us-east-1 outage started and ended, kept apart from both the insurer and the cloud provider, for MGAs and insurers writing parametric cloud-outage cover.
Scope today
Selected API checks against AWS us-east-1. Other regions and providers come later.
Method
The rules for what counts as an outage, and why, are being written up and will be published before anyone relies on them.
Pilot
A small group of firms, free during the pilot, in exchange for feedback on what the data should cover and how outages should be defined.

Nothing on this site is an offer of insurance. Nimbus Index provides data only.
